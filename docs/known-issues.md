# Limites connues

- **Firebase Cloud Messaging** — les options FlutterFire et le compte de service présents localement ciblent `unique-livraison-expresse`; le JSON est valide, exclu de Git, et Firebase Admin s’initialise sans erreur. L’inscription et les appels d’envoi sont implémentés, mais la réception de bout en bout et les droits FCM du compte ne sont pas validés faute d’appareil/jeton actif. La console Firebase n’a pas été vérifiée.
- **Mode hors ligne** — SharedPreferences conserve les actions par utilisateur et les rejoue lorsque le réseau revient; scénario de conflit/réseau à vérifier sur appareil.
- **GPS mobile arrière-plan** — cause : scope MVP limité à la durée de vie active de l’app. Impact : pas de position en arrière-plan ni app fermée. Ne pas annoncer un tracking continu.
- **Vérification appareil** — le build/analyse ne confirme pas permission, réseau, vitesse GPS ou compatibilité sur appareil physique. Tester sur émulateur Android et téléphone avant une démo externe.
- **APK** — un ancien APK debug est présent dans `mobile-livreur/build/app/outputs/flutter-apk/app-debug.apk`; une nouvelle compilation attend le verrou `flutter.bat.lock`. Un `dart.exe` candidat (PID 8804, démarré à 17:09, depuis `C:\Users\USER\source\flutter\bin\cache\dart-sdk\bin\dart.exe`) a été observé avec des processus Dart frères et une date de démarrage correspondant au verrou; Windows a refusé l’accès à sa ligne de commande, donc son rôle exact n’est pas confirmé et il n’a pas été arrêté. L’ancien APK n’est pas validé pour cette configuration ni pour un test distant. Aucun appareil/AVD n’était disponible.
- **Hébergement** — le Blueprint Render est prêt, mais ni le compte Render ni le projet Neon ne sont connectés dans la session. Aucun service ni URL HTTPS n’a été créé. Render Free endort l’API/dashboard après 15 min d’inactivité; Neon Free annonce 1 Go par projet au 4 octobre 2026. Les URL CORS/API devront être renseignées après provisionnement.
- **Contrat API** — Swagger UI à `/api/docs`, OpenAPI JSON à `/api/docs-json` et snapshot `backend/openapi.json`.
- **Logo** — extraction raster de l’affiche JPEG fournie; bords légèrement adoucis/compressés, pas de maître vectoriel.
- **Suppression référentiels** — des clés étrangères de commandes peuvent empêcher de supprimer client/fournisseur déjà utilisés; l’API renvoie l’erreur relationnelle, pas d’archivage métier pour l’instant.
